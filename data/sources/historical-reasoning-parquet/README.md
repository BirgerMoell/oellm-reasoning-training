Nemotron first, all selected rows came from raw Nemotron v2. The second file is English math generated by
`Qwen-2.5-32B-Instruct, DeepSeek-R1`; it is not a Finnish corpus. Only ten-row Finnish translation samples
exist beside it on shared storage.

Keep this artifact for reproducing the published SFT checkpoint and for an A/B data ablation. Production
v1 instead uses decontaminated, pinned sources, token shares rather than concatenation order, and explicit
multilingual reasoning allocations.
